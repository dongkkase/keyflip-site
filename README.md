# KeyFlip

원하는 키로 Mac의 두 입력 언어를 전환하는 메뉴 막대 앱입니다. 이 저장소는 **소개 웹사이트와 배포 자료**를 담고 있으며, 앱 소스 코드는 포함하지 않습니다.

- [소개 페이지](https://dongkkase.github.io/keyflip-site/)
- [다운로드 및 릴리즈](https://github.com/dongkkase/keyflip-site/releases/tag/v0.2.6)
- [설치 안내](https://dongkkase.github.io/keyflip-site/#install)

현재 배포는 **0.2.6 개발 미리보기 · Apple Silicon · macOS 13 이상**입니다. Developer ID 서명과 Apple 공증을 받지 않았으며, 실제 원격 연결·가상 OS·시뮬레이터 입력 조합은 미검증입니다. 자세한 안내는 소개 페이지를 확인하세요.

## English

KeyFlip is a macOS menu bar app that switches between two input sources with a key of your choice. This repository contains the **introduction website and distribution materials**, not the app source code.

- [Website](https://dongkkase.github.io/keyflip-site/?lang=en)
- [Downloads and releases](https://github.com/dongkkase/keyflip-site/releases/tag/v0.2.6)
- [Install guide](https://dongkkase.github.io/keyflip-site/?lang=en#install)

The current release is a **0.2.6 developer preview for Apple Silicon and macOS 13 or later**. It has no Developer ID signature or Apple notarization. Actual remote, virtual-machine, and simulator input combinations remain unverified. See the website for details.

## Website files

The website uses static HTML, CSS, and JavaScript without build dependencies. GitHub Pages serves the repository root. Asset and stylesheet paths are relative, so the site works under the `/keyflip-site/` project path.
